# Ambersong documents

The two books of Ambersong, each as a PDF for a person and as Markdown for an LLM. Start with the Hardware Bible
PDF, and read its mains safety chapter before you open the radio.

| File | What |
|---|---|
| [`Ambersong - Hardware Bible.pdf`](Ambersong%20-%20Hardware%20Bible.pdf) | The cabinet, the boards, power, audio, display, needle and sensors, cables, the antenna, the amplifier and the tube radio, with every schematic sheet. Open this first |
| [`Ambersong - Firmware Gospel.pdf`](Ambersong%20-%20Firmware%20Gospel.pdf) | What the two boards run, how to build, flash and update them, every setting, the portal, the link between the boards, known issues |
| [`hardware-bible.md`](hardware-bible.md) | The Hardware Bible as Markdown; it links its other three files (`-cables`, `-tube-radio`, `-reference`) |
| [`firmware-gospel.md`](firmware-gospel.md) | The Firmware Gospel as Markdown; it links its other eight files (`-main-board`, `-needle`, `-tuning`, `-settings`, `-network`, `-link`, `-sound`, `-known-issues`) |
| [`figures/`](figures/) | The figures of both PDFs: block diagrams and cable drawings (SVG), every schematic sheet (`sheets/`), the main sheet cut box by box (`crops/`), and the photos and animations of the finished radio |

The [`llms.txt`](../llms.txt) file at the root maps the whole repository for an LLM.
